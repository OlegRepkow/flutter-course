## 🔹 Основна інформація

- `name` — ім’я (текст)  
- `lastName` — прізвище (текст)  
- `age` — вік (число)  
- `email` — email (текст)  
- `isVerified` — чи підтверджений акаунт (true або false)  
- `phone` — номер телефону, або `null`, якщо немає  

---

## 🔹 Курси

- `finishedCourses` — список курсів, які пройшов користувач  

Кожен курс містить:
- `name` — назва курсу (текст)  
- `result` — результат, який містить:
  - `score` — кількість балів (число)  
  - `certificate` — посилання на сертифікат (текст)  
  - `certificateType` — тип файлу, наприклад `"pdf"`  
  - `finishedAt` — дата завершення (текст у форматі дати)  

---

## 🔹 Дати

- `createdAt` — дата створення профілю (текст)  
- `updatedAt` — дата останнього оновлення (текст)
