# Завдання: Створи JSON на основі опису курсу

1. Побудуй **валідний JSON**, який відображає інформацію про цей курс.
2. Структура має бути **зручною та логічною**, з вкладеними обʼєктами та масивами.
3. У твоєму JSON повинні бути використані **всі 6 типів даних у JSON**:
   - `String` — рядок
   - `Number` — число
   - `Boolean` — логічне значення (`true` або `false`)
   - `Null` — порожнє значення
   - `Array` — масив
   - `Object` — обʼєкт
